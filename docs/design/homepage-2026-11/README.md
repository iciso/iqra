# Homepage design options (November 2026)

Four directions for the IQRA homepage. Open the .html files in a browser to see each hero; the .png files are screenshots at desktop (1440px) and phone (390px) width.

| Option | Idea | Colours | Fonts |
|---|---|---|---|
| A - The Illuminated Page | A mushaf page you study from; verse-end rosettes hold the numbers | paper #F3EBDD, ink #1F1A14, gold #B0893A, red #A8361F | Amiri, Cormorant Garamond, Literata |
| B - Race to Good | "Race to all that is good" (2:148) as a scoreboard; split-flap leaderboard and a friend challenge | emerald #0F4D33, cream #F1EAD8, lime #E9F04B | Big Shoulders Display, Familjen Grotesk, Red Hat Mono, Noto Naskh Arabic |
| B2 - Race to Good, soft green | Same as B in a calmer sage green | sage #3E6B55, cream #F1EAD8, wheat #E8D9A0, peach #E39B72 | same as B |
| C - The Night of Iqra | 50 subjects orbit a glowing اقرأ like an astrolabe | night #0B1020, lamp gold #F5C76A, sky #8EC5FF | Reem Kufi, Figtree |

All fonts are free (Google Fonts). The build will use the existing Next.js, Tailwind and shadcn setup. Arabic text is never animated.
